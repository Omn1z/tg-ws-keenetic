Доступ к панели

Панель: 1434 по умолчанию. Адрес и порт панели меняются в файле конфигурации с перезапуском сервиса.

Применение переподключит клиентов.

Установка, обновление и удаление

Выполняйте команды через SSH от root на OpenWrt или Keenetic с Entware. Ссылки станут доступны после публикации релиза с готовыми пакетами. Нужен wget с HTTPS.

Инструкция по установке

Установщик выберет архитектуру и последний релиз, проверит SHA-256 и включит автозапуск.

wget -O /tmp/tgws-install.sh https://github.com/Omn1z/tg-ws-keenetic/releases/latest/download/install.sh && sh /tmp/tgws-install.sh

Инструкция по обновлению

Повторите команду установки. Настройки, секрет и пароль панели сохранятся.

Инструкция по удалению

wget -O /tmp/tgws-uninstall.sh https://github.com/Omn1z/tg-ws-keenetic/releases/latest/download/uninstall.sh && sh /tmp/tgws-uninstall.sh

Настройки сохранятся. Для полного удаления вместе с настройками, секретом и журналом добавьте --purge после sh /tmp/tgws-uninstall.sh. Релизы ↗
